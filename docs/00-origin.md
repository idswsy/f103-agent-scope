# 00 · 项目定位与设计约束

## 一句话

一台**能被 AI Agent 直接操控**的示波器 / I2C 总线分析仪 —— AI 一句话就能抓波形、解协议、判断信号质量。

---

## 硬件平台

**立创开源《简易数字示波器设计（入门版）》插件底板 + STM32F103C8T6 核心板**（核心板 + 插件底板结构）。

- 核心板可换：立创 GD32E230 小板 / CW32F030C8T6 小蓝板 / **STM32F103C8T6 小蓝板** ← 本项目选这个
- 模拟前端：BNC → 拨动开关（AC/DC、X1 或 1/50 衰减）→ TL072IP（跟随器 + 比例放大 `Vo=(5−Vin)/2`）→ ADC
- 测频通路：LM393P 滞回比较器 → 定时器输入捕获
- 电源：Type-C **仅供电**，XD7660 产生 −4.3V 负压供运放测负半周
- 交互：EC11 旋转编码器 + 3 按键 + 1.8 寸 TFT（ST7735，128×160，四线 SPI）
- 量程：低压 −1.6V~5V；高压 −80V~250V

**上游留下的一片空白**：现有固件只做本机采集 + 屏幕显示，**没有任何对外命令协议、没有上位机接口、没有波形导出通道**，Type-C 还是纯供电。
换句话说 —— **接口层要从零做**，这正是本项目的软件工作量所在。

---

## 四条约束决定了整体架构

| 约束 | 物理原因 | 设计后果 |
|---|---|---|
| **无以太网** | F103C8T6 没有 MAC / RMII 外设 | 主传输走 UART / USB CDC（[ADR-003](06-decisions.md)） |
| **无 FSMC** | 中容量型号，无外部存储控制器 | 单次采集锁 4096 点，不做深存储（[ADR-004](06-decisions.md)） |
| **只有 2 个 ADC** | 72 MHz + USB 下 ADCCLK 上限 12 MHz | 双通道同步 857 kSPS，解不了高速协议 → 需要第二条通路 |
| **接口层为空** | 上游固件无对外协议 | 协议 / 上位机 / Agent 全栈自研 |

---

## 核心设计：双通路

「ADC 采样率不够高」是这类平台的通用难题。857 kSPS 在 100 kHz I2C 下舒适，但：

| I2C 速率 | 判定 START/STOP 所需采样率 | 857 kSPS |
|---|---|---|
| 100 kHz | 0.50 MSPS | ✅ 舒适 |
| 400 kHz | 3.33 MSPS | ❌ 差 3.9× |
| 1 MHz | 7.69 MSPS | ❌ 差 9× |

更麻烦的是**采样相位拍频**：857 k @ 400 kHz 时采样相位只有 15 个离散值，两颗晶振 40 ppm 的频差会让解码**以 ~62 ms 为周期时好时坏地闪** —— 这是采样体制问题，**软件补不了**。

**解法不是堆采样率，而是换一种时间测量方式。**
板上那颗 **LM393P 滞回比较器**（原设计只用来测频率）接到定时器输入捕获后，得到 **72 MHz / 13.9 ns 的边沿时间戳**，等效 ~72 MSPS，且**免疫混叠、免疫采样相位、免疫时钟拉伸**。

于是两条通路各司其职：

| 通路 | 硬件 | 回答的问题 |
|---|---|---|
| **协议通路**（权威） | LM393 → TIM 输入捕获 | 协议**对不对** —— 100k / 400k / 1MHz 全部可靠 |
| **模拟通路**（差异化） | TL072 → ADC 857 kSPS | 信号**好不好** —— 电平裕量、上拉强度、振铃、边沿形状 |

ADC 通路不必再勉强去解高速协议，可以专注它真正擅长的事：看清信号质量。详见 [ADR-005](06-decisions.md)。

## 本项目定位

> **一台给 AI 用的调试眼睛**：能自动抓 I2C/串口总线、解出协议、并同时告诉你信号质量好不好。

不是计量仪器。KPI 不是「多少位有效精度」，而是：

1. **Agent 能不能一句话拿到想要的波形/协议/测量结果**
2. **拿到的东西对不对**（解码必须 100% 可靠，宁可说"不知道"也不给看似精确的垃圾数）

## 能力边界（写死在文档里，防止后期被当成 bug）

| 能 | 不能 |
|---|---|
| I2C 协议解码 100k / 400k / 1MHz | I2C 时序合规性验证（tSU;DAT / tr 的 ns 级判定） |
| 模拟观察 ≤ 100 kHz | 带宽 > 0.5 MHz |
| 双通道同步 857 kSPS | 1 MSPS 与 USB 并存 |
| 单次 4096 点 | 深存储 / 外扩 SRAM |
| 低频、电源纹波、音频、总线分析 | 计量级测量、THD / SFDR、12-bit 绝对精度 |
| 高/低压两档（机械拨动开关切换） | AI 程控量程（需改板，见 P4） |

## 主板升级路线

上述「无以太网 / 无 FSMC / 只有 2 个 ADC」三条约束都是 **F103C8T6 这一颗芯片**带来的，不是项目本身的边界。
升级到 **STM32F407**（自带以太网 MAC、FSMC、三 ADC）后：

- 采样率：三 ADC 三重交替 → **7.2 MSPS**，模拟通路可单独覆盖 400 kHz
- 存储深度：FSMC 外挂 SRAM → 深存储
- 传输：以太网 → 直接传原始波形

**数字通路长期保留** —— 它在 1 MHz I2C 下仍有不可替代的价值（免疫混叠与相位问题）。
